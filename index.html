Installation

// Quick Start — Windows

1
Download the latest .zip above and extract to any folder (e.g. D:\Games\LockESC\)
2
Install Python 3.11+ from python.org — tick "Add to PATH"
3
In the extracted folder: pip install pygame
4
Launch: python lockesc_tracebackfinder.py or double-click run_lockesc.bat
5
Custom levels → %USERPROFILE%\levels\  ·  Multiplayer → %USERPROFILE%\mplevels\
