// Upload a Level

📦

Levels are shared as GitHub Issues.
Attach your .ler or .lep bundle (zipped),
fill in the template, and submit.

OPEN ISSUE ON GITHUB ↗
How it works: clicking the button takes you to GitHub's new issue form, pre-filled with a template. Attach your level ZIP to the issue body (drag & drop into the text area), add the label level-submission, and submit. Your level will appear here once the issue is open.

Label guide:  sp singleplayer  ·  mp multiplayer  ·  easy medium hard  ·  puzzle speedrun no-kill

// How to Install

1
Click a level card below and hit DOWNLOAD — or grab the ZIP attached to the GitHub issue
2
Extract the ZIP — you should see a folder ending in .ler or .lep
3
Drop the bundle folder into the right location:
SINGLEPLAYER%USERPROFILE%\levels\ MULTIPLAYER CO-OP%USERPROFILE%\mplevels\
4
Launch LockESC — level appears under CUSTOM in the level picker
// .LER BUNDLE STRUCTURE
my_level.ler/ ← bundle folder ├── room.ler ← JSON data └── assets/ ← optional tiles Required keys in room.ler: "tiles": [[row, col, "type"], ...] "player_start": [tx, ty] "next_level": "../next.ler" (optional)
